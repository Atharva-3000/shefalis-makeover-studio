# Shefali's Makeover Studio — Custom Website Concept

Static, mobile-first HTML/CSS/JS website concept created as a replacement pitch for the existing Wix site.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design system
- `script.js` — tiny enhancement for the footer year and anchor links

## Hosting
No build step or framework is required. Upload all three files to any normal static host or web root.

## Before the client launch
1. Replace the four current Wix-hosted images in `index.html` / `styles.css` with approved original salon photos. The current concept deliberately references public images from their existing site so the pitch can visually resemble their current work.
2. Confirm the final address and business hours.
3. Confirm current bridal pricing before publishing the ₹6,000 starting price shown in the concept.
4. Add the salon's real Instagram/Facebook links.
5. Connect the final custom domain and analytics.
